# Style Explorer

Explore › Styles shows style codes with a real preview, so you can see a look before using it.

## Tabs

| Tab | Shows |
| --- | --- |
| Discover | **Discover 8 styles** renders previews of 8 random codes. |
| Likes | Codes you saved with the heart. |
| Used | The codes of your creations. |

Search finds codes by the names of the styles they mix.

## Previews

Each preview is a draft H3 Image of the **preview prompt** with the code, always with the same seed, so previews of different codes are comparable. The previews are made one at a time and kept, so each code is rendered only once. Change the preview prompt on the [ComfyUI page](#comfyui-settings).

## Using a code

Open a style to see its preview and the styles it mixes. **Try style** runs your current prompt with it; **Copy --sref** puts the code in the bar. Liking a style also teaches your global [personalization](#personalization) profile.
